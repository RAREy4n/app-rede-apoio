# Backend

O backend ainda não foi implementado. A pasta existe para separar futuras responsabilidades de servidor do aplicativo Flutter e da landing page.

## Possíveis responsabilidades futuras

- Autenticação e gestão de consentimento, se forem realmente necessárias.
- Cadastro seguro de pessoas de confiança.
- Catálogo curado de serviços e organizações de apoio.
- Auditoria mínima de operações sensíveis.

## Restrições obrigatórias

- Não guardar localização contínua por padrão.
- Não guardar evidências, relatos ou documentos sem base legal, desenho de segurança e política de retenção.
- Não enviar BO, alertas policiais ou dados a órgãos públicos sem parceria oficial validada.
- Projetar com LGPD, minimização de dados, revogação de consentimento e controle de acesso desde o início.
